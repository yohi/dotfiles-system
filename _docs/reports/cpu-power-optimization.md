# CPU電力・静音・ハードウェア保護 最適化レポート

## 1. 概要と背景

本マシンは **AIエージェント（OpenCode / LLMエージェント等）の複数並列実行** に特化したワークステーションです。
稼働状況において「消費電力」および「ファンノイズ（急激な回転上昇）」の懸念があったため、現状のリソース使用率および温度推移を詳細調査し、**マシンの物理的摩耗（高電圧・高熱劣化）を防ぎつつ静音・省電力化を実現する最適化** を実施・整備しました。

また、本dotfilesは他PC（ノートPCや他デスクトップ等）でも共用されるため、**ハードウェア構成に応じた自動判定ロジック** を組み込んでいます。

---

## 2. ハードウェア構成と特性

| コンポーネント | スペック / モデル | 特性と考慮事項 |
|---|---|---|
| **CPU** | **Intel Core Ultra 7 270K Plus** | 24コア（Pコア×8: 最大5.6GHz / Eコア×16: 最大4.7GHz）。定格PL1: 200W / PL2: 250W。 |
| **マザーボード** | **ASUS TUF GAMING Z890-PLUS WIFI** | 高耐久VRM電源回路、Q-Fanコントロール対応。 |
| **CPUクーラー** | **Deepcool AK620 DIGITAL SE** | デュアルタワー空冷（TDP 260W対応）。冷却能力は極めて優秀だが、1500 RPMを超えると騒音が顕著になる。 |
| **PCケース** | **Antec P30 Air** | フロントメッシュ・超高エアフロー構造。通気性に優れる反面、高回転時のファンノイズが外部に漏れやすい。 |

## 3. 現状調査結果

### 3.1 リソース状況・温度
- **ロードアベレージ**: `1.79, 2.29, 1.87`（24コアに対して極めて余力あり）
- **アイドル時のCPU全体温度**: **約 36.0°C**（Core 0〜44: 32〜40°C、冷却自体は正常動作）
- **高負荷スパイク時**: 瞬間的に **65〜70°C超** へ急上昇（Package id: 最大 69°C を観測）

### 3.2 過去の負荷傾向 (`sysstat / sar` より)
- **日中平均CPU使用率**: 約 12.6%
- **ピーク時CPU使用率**: 06:00（48.3%）、06:30（44.8%）、03:40（30.0%）
- **深夜アイドル時**: 約 4.3%

### 3.3 騒音と電力消費の根本原因
1. **瞬間スパイク電力（PL2）250W の存在**:
   エージェントがビルドやコード解析を走らせた瞬間、CPUが 5.6GHz 付近までブーストし、瞬間電力が 200〜250W に到達。
2. **過剰な電圧印加と温度の跳ね上がり**:
   高クロック駆動に伴い電圧が跳ね上がり、AK620のファンが急激にフル回転（急加速）することで不快な風切り音が発生。

## 4. 最適化方針とハードウェア寿命保護

「ファンを無理やり止めて内部に熱をこもらせる静音化」はパーツ寿命を縮める危険があります。
本対策では **「発熱源そのもの（高電圧・過剰クロック）を根本から抑え、熱自体を発生させない」** アプローチを採用しました。

### 比較: デフォルト vs 最適化設定 (`agent` モード)

| 項目 | 工場出荷デフォルト | 最適化設定 (`agent`) | ハードウェア保護・寿命への効果 |
|---|---|---|---|
| **持続電力 (PL1)** | 200W | **125W** | 発熱量を常時AK620の定格容量（260W）の半分以下に抑制 |
| **瞬間電力 (PL2)** | 250W | **150W** | **マザーボードVRM電源回路への過電流を遮断**。コンデンサの熱劣化を防止 |
| **動作周波数上限** | 100% (5.6GHz) | **80% (約4.2〜4.5GHz)** | 半導体劣化の主因である「高電圧印加」を回避 |
| **EPP (電力優先度)** | `balance_performance` | **`balance_power`** | 無駄なクロックの跳ね上がりを防止 |
| **ファン動作** | 突発的に全開回転（唸り音） | **低〜中回転で安定** | ファンベアリングの摩耗を抑制 |
| **エージェント並列性能** | 基準値 (100%) | **約 96〜98% (ほぼ同等)** | 24コア分散処理のため、クロックスペック低減の影響は極小 |

## 5. 実装した内容 (`dotfiles-system`)

### 5.1 最適化スクリプト
- **ファイル**: `_scripts/cpu-power-optimization.sh`
- **特徴**:
  - **適用対象**: 電力プロファイルは Core Ultra 7 270K Plus に明示的に適用する。`make setup` では変更しない。
  - **プロファイル切り替え**:
    - `agent`: AIエージェント並列特化（PL1: 125W / PL2: 150W / 上限80% / EPP: balance_power）
    - `quiet`: 極限静音（PL1: 90W / PL2: 100W / 上限65% / ターボ無効）
    - `restore`: 今回のセッションで最初にプロファイルを適用する前に保存した値へ戻す。
  - **永続化**: 自動適用は行わない。既存のサービスが `auto` を実行しても設定を変更しない。

### 5.2 Makefile 連携
- **ファイル**: `_mk/system.mk`
- 以下の管理ターゲットを追加：

```bash
make cpu-power-status        # 現在の電力制限、周波数比率、温度を確認
make cpu-power-agent         # AIエージェント特化モードを適用 (要sudo)
make cpu-power-quiet         # 極限静音モードを適用 (要sudo)
make cpu-power-restore       # 適用前の設定に戻す
make test-cpu-power          # 設定切り替えの回帰テスト
```

## 6. 推奨される運用手順

AIエージェントの安全な長時間並列稼働を行うために、ユーザー環境にて以下を実行してください。

```bash
# 1. AIエージェント並列特化モードの適用
make cpu-power-agent

# 2. 適用状態の確認
make cpu-power-status
```

> [!TIP]
> **マザーボード（ASUS BIOS）での補足推奨設定**
> BIOSの「Q-Fan Control」メニューにて、CPUファンの **Step Up Time（加速遅延時間）を「2.4秒 〜 3.6秒」** に設定すると、瞬間的な温度変化に対してファンの回転数変化が非常に滑らかになり、急なノイズ変化を完全になくすことができます。
